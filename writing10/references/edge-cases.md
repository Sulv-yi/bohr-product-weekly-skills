# 异常矩阵：七类失败与处置

| 情况 | 识别信号 | 处置 | status |
|---|---|---|---|
| 缺图注 | 正文有（图 n）但无题注 | 补题注：内容、n、误差棒含义；补不出改文字描述 | `partial` |
| 图注无 n 或误差棒含义 | `n` 字段空 / 只说"误差棒" | 补实数；确实没有就写"未标注"，并作为局限 | `partial` |
| 有数值无统计量 | 出现"显著"但无 p/CI/检验名 | 补检验；给不出把"显著"改"方向一致" | `partial` |
| 单位不明或需换算 | 材料单位与目标单位不同 | 以材料单位为准；换算写明关系式，不静默换算 | `partial` |
| 图上读数不清 | 散点重叠、误差棒超出坐标 | 不猜数值；写"图上无法读数"，列入 uncertainty | `partial` |
| 引用找不到全文 | 只有题录或摘要 | 只作背景引用，不用于数值比较 | `partial` |
| 文件缺失/权限不足 | 路径不存在或读报错 | 不猜内容，`status=blocked`，写清缺什么 | `blocked` |

## 其余情况

- **阴性结果**：写"未观察到 X"，不写"X 无影响"（后者需等效性检验）。
- **显著性边界**（p 在 0.05–0.1）：写"方向一致但未达显著"，并给 p 值。
- **多面板图**：图 2A/2B 分开建 `figure_data` 行，不合并。
- **重复测量**：技术重复不提升证据等级；写成"同一试样的三次测量"。
- **预算将尽**：先落结果段 + `figure_data` + 局限，标 `partial`，再补讨论。

## 不许做的三件事

1. 编一个"约 60%"来匹配图上的 62%——数值一致率会把它揪出来；
2. 用"差异明显"替代显著性表述；
3. 把 `partial` 改成 `success` 绕过门槛。
