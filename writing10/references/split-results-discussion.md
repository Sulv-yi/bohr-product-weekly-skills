# 结果段与讨论段的分工

这是本题最容易失分的地方：两节互相顶替——结果段里写"说明机制"，讨论段里重新罗列数字。

## 结果段（只写观察）

允许：
- 数值 + 单位 + 出处 `（图 1）`；
- 组间比较与方向 `高剂量组低于对照组`；
- 统计量 `（p=0.012，t 检验）`；
- 阴性结果 `未观察到死亡`。

不允许（出现即计入 `leakage`）：
- 解释性连词与判断：因为、由于、说明机制、可能源于、归因于、其机制、可解释为；
- 与文献对照 `与…报道一致`；
- 意义评价 `这提示该化合物具有应用前景`。

上限 2 句：确实需要一句过渡时可以用，但超过 2 句说明两节没分开。

## 讨论段（解释与对照）

必须包含四类内容，缺哪类就在自检表里标注：

1. **主结果复述**（一句，带数值，不重复罗列全部数字）；
2. **与文献对照**：一致/不一致 + 可能原因（体系、剂量、测量口径、样本）；
3. **机制推测**：写明"可能"，并说明本文是否测了关键中介变量；
4. **边界**：结果不能换算成什么（如体积降幅不能换算为生存获益）。

## 局限段（具体化）

合格：`每组 8 只、单中心、单批次，样本量不足以检出小于 20% 的组间差异`；
`未设阳性对照药`；`未做生存分析`；`观察期 21 天，未覆盖停药后恢复`。

不合格：`样本较少`、`有待进一步研究`、`受条件限制`——脚本会把这些列为套话。

## 自检

```bash
python scripts/validate_result.py result.json --text chapter.md
# leakage=0      结果段无解释句
# 结果=317 字    讨论=896 字  两节都有实质内容
```
