# 与已有方案的边界

## 1. 比较对象

| 方案 | 擅长 | 在本任务上的缺口 | 本 Skill 的位置 |
|---|---|---|---|
| 基础 Agent | 行文流畅、能把要点串成段落 | 数值常写成"约""明显"；"显著"不带统计量；结果段夹解释；局限写套话 | 把数值回溯、统计对齐、泄漏、局限具体性四项变成可计算门槛 |
| 通用写作助手 | 结构模板与语气 | 不读数据表，图表数值靠猜；不区分结果与讨论职责 | `figure_data` 作为唯一数值来源，正文只能引用它 |
| 统计软件输出解读工具 | 解释 p 值与效应量 | 不检查正文表述是否超出统计证据；不管与图是否一致 | 逐句核"显著"是否有统计量；逐值核正文与图表 |
| 图表检查工具 | 图表本身是否规范 | 不检查正文引用与图注是否成对、数值是否一致 | `figure-audit.csv` 建立正文↔图表映射 |

## 2. 新增能力落点

1. **数值逐值回溯**（`fig_number_rate`）：正文每个「数字+单位」与 `figure_data` 的数值规范形比对，
   单位不进比较、符号按绝对值（正文"下降 2.1%"与图表 `-2.1` 同值）。
2. **显著性↔统计量对齐**（`stats_alignment`）：抓出所有含显著性措辞的句子，检查是否带 p/CI/检验名。
3. **两节分离检出**（`leakage`）：结果段出现解释性连词即计数，上限 2 句。
4. **局限具体性**（`limitation_markers`）：用 `n=`、`单中心`、`未做对照`、`随访` 等线索计分，
   "样本较少"不计分并单列。

## 3. 明确做不到的

1. **不做统计复核**：只查"有没有统计量"，不判断检验选得对不对、是否满足前提。
2. **不读图像像素**：数值必须已在数据表或图注文字里；从图像目测读数不在范围内。
3. **不判断生物学意义**：效应量大小是否有临床价值，需要领域判断。
4. **不查剂量组标签是否写反**：脚本只能查数值是否一致，标签对错需人工核。
5. **不做英语学术润色**：本 Skill 只保证数值、统计与结构，不保证语言地道。

## 4. 边界写在这里的用途

评审可以据此判断哪些分是本 Skill 挣的、哪些不是；也便于他人按学科替换阈值后复用。
