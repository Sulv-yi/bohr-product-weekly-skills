# 最小示例：一段摘要改科普

输入：500 字技术摘要（含 3 个缩写、6 个数值、2 条限定条件）、目标读者为公众。

## 成稿（节选）

> **给谁看、读完能知道什么**：关心储能但没材料背景。读完你会知道这项改动把效率提了多少，以及这个数在什么条件下成立。
>
> 电池第一次充电进去的能量，第二次取不回来全部。取回的比例叫首次库仑效率（initial Coulombic efficiency，ICE）——它决定了出厂时有百分之多少的库存是白搭的。
>
> 我们换了工艺后，这个比例从 82.3% 升到 88.6%，同批三只电池的差别不到 1 个百分点【源：源文 §3】。不过这些数据都来自纽扣半电池，循环仅测到 200 周【源：源文 §4】。

## 自查

```bash
python scripts/validate_result.py result.json --case case.json --text draft.md
# 字数=420 节=2 缩写展开=100% 数值=100% 限定条件=100% 溯源=100%
# 门槛未通过: 篇幅 <900；节数 <3；类比 1 处 <2
```

三条不过是有意的：这段只演示"证据怎么留"，没演示"怎么讲清楚"。
补齐的方式是加两节（现象解释、边界说明）和至少一个类比——门槛要求的是完整稿，不是片段。
