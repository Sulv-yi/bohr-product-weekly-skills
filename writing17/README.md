# 科研成果转化写作 Skill

论文改科普，最容易出的问题不是文笔，是**证据在改写中蒸发**：数值被四舍五入、限定条件被删掉、
"初步结果"变成"已经证明"。这个 Skill 把四件事做成可执行判定：

| 尺 | 问什么 | 判据 |
|---|---|---|
| 读得懂 | 目标读者不补背景能不能读 | 缩写展开 ≥90%、长句 ≤30%、类比 ≥2 |
| 留得住 | 数值与限定条件还在不在 | 数值 ≥90%、限定条件 ≥70%、图表 ≥90% |
| 说得准 | 论断强度和证据对不对得上 | 限定语保留 ≥80%、越界断言 0、术语漂移 0 |
| 接得住 | 原作者能不能接着改 | 改动账覆盖 ≥80%、溯源 ≥80% |

## 自测（examples/）

| 项 | 成稿 | 基线（直译压缩） |
|---|---|---|
| 字数 | 1575 | 236 |
| 缩写展开 | 100% | 43% |
| 数值保留 | 96% | 48% |
| 限定条件 | 100% | 0% |
| 限定语保留 | 100% | 0% |
| 越界断言 | 0 | 3 |
| 术语漂移 | 0 | 3 |
| 溯源覆盖 | 95% | 0% |
| 评分卡 | 16 pass / 0 fail | 5 pass / 9 fail / 2 n/a |

## 边界

不判断选题价值、不生成原文没有的数据、不做事实核查（只能检查"是否挂了溯源"，不能确认溯源对不对）。
详见 `references/innovation-boundary.md`。
