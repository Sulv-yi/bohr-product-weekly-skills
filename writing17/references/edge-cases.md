# 异常与降级矩阵

| 情况 | 表现 | 处理 |
|---|---|---|
| 源文缩写无全称 | 只有 ICE，没有 "initial Coulombic efficiency" | 不展开，改写中文描述；uncertainty 记一条 |
| 源文数值自相矛盾 | 摘要写 88.6%，结果节写 87.9% | 两处都写，注"源文不一致，未取舍" |
| 源文无图表编号 | 只说"如图所示" | 图表门槛分母为 0，记 100%；正文改用"下表中的数据" |
| 源文本身是二次转述 | 引用别人的数据但未标出处 | 溯源标到"源文 §x"，并在 uncertainty 说明无法回溯到原始文献 |
| 目标读者需要确定性 | 公众希望"行不行"的答案 | 保留 hedge，另加"这意味着什么/不意味着什么"两句 |
| 材料只够写 300 字 | 源文是短摘要 | 降级为问答式，逐条回答读者会问的问题，不编背景凑字数 |
| 多篇材料合并 | 数值口径不同 | 统一口径后再比；无法统一则分列，不做跨口径的百分数 |
| 术语表与其他产出冲突 | 同一项目两篇稿子译法不同 | 以术语表为准，另一篇回改；不允许"每篇各自锁定" |
