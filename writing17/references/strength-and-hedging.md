# 论断强度与限定语

## 三档强度

| 档 | 语言标志 | 源文对应 |
|---|---|---|
| 强 | 证明 / 证实 / 确认 / 必然 | 有对照、有统计检验、可重复 |
| 中 | 表明 / 显示 / 提示 / 支持 | 有数据但样本有限或未做对照 |
| 弱 | 可能 / 推测 / 倾向于 / 尚不清楚 | 单点观察、机理性推断 |

## 改写规则

1. **只能降，不能升**。源文说"提示"，改写最多说"表明"，不能说"证明"。
2. **升档必须给依据**：若成稿用了强断言，句中必须有 hedge 或溯源标记，否则脚本记一条越界。
3. **降档不算错**，但要在改动账里写理由（"源文样本 n=3，改写降为'提示'"）。

## 常见的强度事故

| 源文 | 事故写法 | 为什么是事故 |
|---|---|---|
| 该结果提示…可能… | 该结果证明… | 把机理推断说成定论 |
| 在纽扣半电池中… | 在全电池中… | 测试体系被悄悄放大 |
| 200 周保持率… | 长循环性能优异… | 时间尺度被抹掉 |
| 相关系数 0.82 | 两者存在因果关系 | 相关写成因果 |

## 检查口径

`strength_align()` 取成稿里含强断言词的句子，逐句看是否有 hedge 或 `【源：…】`。
两者都没有的，记一条越界。这条判定**只看形式**——它不能判断"这句强断言其实是对的"，
只能保证作者必须给出依据位置，让读者自己去核。
