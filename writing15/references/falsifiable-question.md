# 立得住：缺口具体、问题可证伪

## 1. 缺口的三段式

背景段不是综述，是一条推导链：

```
已知（挂引用） → 未知（缺口句） → 待验证（本课题做什么）
```

缺口句必须**指向本课题的问题**，判断标准是：缺口句与问题段共享主题词。
只写"该领域仍有广阔研究空间"不算缺口——那句话对任何课题都成立。

可用线索词：`尚未`、`未见`、`缺乏`、`不清楚`、`尚无`、`仍不`、`空白`、
`has not been`、`remains unclear`、`少有研究`。

反例（背景与问题脱节，实测被抓）：
> 背景写"压电材料在骨修复中受到关注"，问题写"探究打印温度对支架的影响"。
> 两句各自成立，但缺口与问题不是一回事，评审会问"为什么非要现在做这个"。

## 2. 可证伪的四个要件

| 要件 | 作用 | 例子 |
|---|---|---|
| 指标 | 量什么 | 孔隙率、压缩模量、d33、ALP 活性 |
| 阈值 | 多少算成立 | ≥70%、≥8 MPa、≥30% |
| 对照 | 跟谁比 | 纯 PLA 组、同日培养对照、基线模型 |
| 时间点 | 什么时候测 | 第 12 月、第 14/21 天 |

四件缺一件，问题就退化成"探究性描述"。实测：只写"探究 X 的影响"，
`falsifiable=false`，`result_correctness` 直接判 fail。

正例：
> Q1：填料分数由 3.5 wt% 增至 10.5 wt% 时，能否在压缩模量 ≥8 MPa 的同时保持孔隙率 ≥70%？
> 判断标准为每组 n = 24、以纯 PLA 为对照、第 12 月完成测试；任一阈值越界即判该假设不成立。

## 3. 问题数量与粒度

- 1–3 个问题；超过 3 个，24 个月做不完，评审会先质疑可行性。
- 每个问题对应 1–3 个目标；问题多、目标少（或多个问题挂同一个目标）是"对不上"的典型。

## 4. 假设写不写

写了更好：把"预期方向"先说明（如"预计 7.0 wt% 组出现最优权衡"），
这样结果出来无论是正是负都能判——只写"能否"，负结果也算回答了问题。
但**不要**把假设写成结论（"将会显著提升"），那是把待验证写成了已验证。

## 5. 检查口径

- `gap_specific`：背景段有缺口线索词，且与问题段中文 2-gram 重叠 ≥2 个；
- `falsifiable`：问题段同时含指标、阈值词、对照/时间点三类。

两项都在 `scripts/validate_result.py` 里，`--json` 可看到具体缺哪一类。
