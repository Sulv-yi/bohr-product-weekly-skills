# 异常矩阵：什么情况怎么处置

判据：**能问就问，问不到就标注，绝不编。** 开题报告里编一个"预期成果"，评审一查就知道；
标一个"材料未给"反而显得清楚。

| 情况 | 识别信号 | 处置 | result 里的落点 |
|---|---|---|---|
| 缺课题指南 | 材料只有前期数据 | 先索要周期、人力、经费、考核要求；要不到就按最常见配置写并在 `uncertainty` 声明 | `uncertainty: guideline_missing` |
| 周期过短 | 指南周期 < 任务量的最低需求 | 缩范围（体内验证移出本期）或写条件触发分支 | `uncertainty: scope_adjusted` + 理由 |
| 人力不明 | 未给可用人力 | 按"1 名博士生全职 + 0.5 技术员"折算，写明折算口径 | `plan.capacity_note` + `uncertainty` |
| 经费未给上限 | 无预算约束 | 按量级估算，仅作相容性校验，声明不作申报依据 | `uncertainty: budget_not_reported` |
| 指标不可达 | 前期数据表明阈值不可能达到 | 下调阈值并写明依据，或改成相对提升（较对照 +X%） | `uncertainty: threshold_unreachable` |
| 学科规范冲突 | 两个标准给出不同测试条件 | 选一个并注明标准号，另一写法进 `uncertainty` | `uncertainty: standard_conflict` |
| 引用无法获取 | 文献只有题录没有全文 | 只作背景引用，不用于支撑具体数值 | `sources` 标 `abstract_only` |
| 前期数据缺失 | 没有预实验数据 | 目标改为"建立基线"，不编已有结果 | `uncertainty: no_preliminary_data` |
| 伦理审批未定 | 动物/人体实验无批件 | 该步骤写成条件触发 + 风险条目，不写"已获批准" | `uncertainty: ethics_pending` |
| 多学科交叉 | 指南与材料学科不一致 | 以材料学科为主，术语与指标按材料口径 | `uncertainty: discipline_conflict` |
| 预算分项不符 | 分项合计 ≠ 总额 | 调整分项使合计相等，或在 `uncertainty` 注明差额来源 | `plan.budget` + `uncertainty` |
| 预算将尽 | 剩余请求不足以写完 | 先落七要素骨架 + 前四节 + plan，标 `partial` | `status: partial` + 未完成节名 |

## 处置优先级

1. **先保证已写部分能被考核**：宁可交五节有指标，也不要七节全是"探索"。
2. **再保证结构完整**：七要素齐（哪怕某节短）比缺两节好，因为缺节是硬门槛。
3. **最后追篇幅**：字数是在前两条之后才追求的量。

## 不要做的事

- 不要为了让"排得开"通过而虚增可用人力（`capacity_pm` 必须来自指南或明确折算口径）；
- 不要把风险写成"若出现问题将及时调整"——四要素缺三，等于没写；
- 不要在 `status` 写 `success` 而七要素缺项。
