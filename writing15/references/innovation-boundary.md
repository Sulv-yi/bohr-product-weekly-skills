# 方案边界：本 Skill 管什么、不管什么、比什么强

## 1. 管什么

四件可计算的事：

1. **立得住**：背景是否有推导到缺口的链（缺口线索 + 与问题段主题词重叠），
   问题是否含指标、阈值、对照/时间点；
2. **对得上**：目标-路线-指标-成果的四元组对齐率，指标是否在正文呼应；
3. **排得开**：里程碑是否覆盖全周期、是否重叠、工作量是否 ≤ 可用人力；
4. **说得清**：风险四要素完备率、类型覆盖数、论断挂引用率。

## 2. 不管什么

| 不做 | 原因 |
|---|---|
| 判断科学价值高低 | 需要领域判断，脚本量不出，也不该由写作工具裁决 |
| 替作者定阈值 | 阈值来自前期数据与文献，工具只检查"有没有阈值、是否在正文呼应" |
| 编造前期数据 | 缺数据就改成"建立基线"，不补数字 |
| 决定学科规范冲突的胜负 | 选一个并注明标准号，冲突进 `uncertainty` |
| 代写经费预算的合理性论证 | 只校验分项合计与总额一致 |

## 3. 与"通用写作助手"的差别

| 维度 | 通用写作助手 | 本 Skill |
|---|---|---|
| 输入 | 一句话主题 | 课题指南 + 前期数据 + 周期 + 人力 |
| 结构 | 自由发挥 | 七要素固定节名，缺节直接失败 |
| 问题 | 常写"探究 X 的影响" | 强制四要件，不可证伪不通过 |
| 目标与路线 | 各写各的 | 四元组映射，断裂逐条列出 |
| 计划 | "分三个阶段" | 月份 + 人月 + 覆盖/重叠/人力比 |
| 风险 | "可能遇到困难" | 四要素 + 四类覆盖，缺项列名 |
| 输出 | 一篇文档 | 稿件 + plan 结构 + 四张台账 + 自查 |

## 4. 与"基础 Agent 直接写开题报告"的差别

基础 Agent 能写出**读起来像开题报告**的文本，但通常：

- 背景是综述，读完不知道缺口（`gap_specific=false`）；
- 问题是"探究…的影响"，无法被数据推翻（`falsifiable=false`）；
- 目标、路线、指标各写一段，互不呼应（`alignment_rate` 低）；
- 计划只有"三个阶段"，没有月份与人月（`schedule_coverage=false`）；
- 风险只有"可能延误"，没有触发信号（`risk_complete=0%`）。

本 Skill 把这五项变成可数的比率与布尔判定，并给达标线。改没改好，看脚本输出。

## 5. 增益的边界（诚实说明）

- 增益在**结构完备性与可复核性**，不在"思想深度"。创新点仍要人想；
- 依赖输入质量：指南与前期数据越具体，缺口与阈值越站得住；
- 极短周期（≤6 个月）或纯理论研究上，人月与里程碑的门槛会显得机械，此时应缩范围而非硬套；
- 学科术语差异大的题目（人文、艺术），"指标 + 阈值"的强制可能不适用，应改用量化程度较低的判据并在 `uncertainty` 说明。

## 6. 为什么不追求"一键生成开题报告"

一键生成的前提是"知道该研究什么"，那是科学判断。本 Skill 的选择是：
**把不可判断的（价值、创新、阈值合理性）交给人并显式标出，把可判断的（结构、对齐、排期、风险完备）做到可计算。**
所以它产出的是"可以交给导师改的稿子 + 一张能被逐行核对的自检表"，而不是更漂亮的文章。
