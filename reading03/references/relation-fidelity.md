# 关系保真（Relation Fidelity）

## 目标
指代、否定与限定、因果让步、数字单位、公式与文献编号**与原文一致**。翻译里一个 `not` 丢掉就可能让结论完全反转——这类"硬损伤"必须机械回扫。

## 六类必须守恒的硬信息

### 1. 数字与单位
原文的数值、范围、比较符、单位必须在译文原样保留或等值转换。
- `30 nm` → `30 nm`（不可写成 `30 μm`）
- `p < 0.05` → `p < 0.05`（不可丢了不等号）
- `10–15%` → `10%–15%`（范围不可漏端点）
- `three-fold` → `3 倍`（等值，但需与原文数字对应）

### 2. 引用标记
`[12]`、`(Smith et al., 2020)`、`Ref. 7` 等编号保留且不串位。译文里 `[12]` 变成 `[21]` 是硬错误。

### 3. 图表与公式编号
`Fig. 2`、`Table 3`、`Eq. (4)`、`Scheme 1` 对应保留。译文说"如图 3 所示"而原文是 Fig. 2，判失败。

### 4. 否定词
`no / not / never / without / neither / nor / fail to / lack` 必须在译文有对应否定。
- 原文：`No significant difference was observed.`
- 错译：`观察到显著差异。`（否定丢失 → 结论反转）
- 正译：`未观察到显著差异。`

### 5. 限定与转折
`only / merely / however / although / whereas / despite / tend to / may / suggest` 限定强度不可升级或降级。
- `may cause` 不可译成 `导致`（强度升级）
- `only in X` 不可译成 `在 X 中`（限定范围丢失）

### 6. 指代对象
`this / these / it / they / the former / the latter / such` 的指代要在译文中明确（必要时补出被指对象），不可含混。

## 自动回扫
`verify_translation.py` 对 1–5 类做机械比对：抽取原文与译文中的数字串、单位串、引用编号、图表公式编号、否定词集合，逐段比对是否守恒；不守恒即列出 `source_id` / 类型 / 原文值 / 译文缺失或改动，判失败。

第 6 类（指代）与语义级误译**无法机械判定**，必须人工复核；脚本会在输出里提示 `semantic_review_required: true`，译者据此在 `uncertainty` 中如实说明。

## 失败处理
守恒失败 → 修正对应段译文 → 重跑回扫，直到通过或明确写入 `uncertainty`（如"原文该句为扫描图片，无法确认否定词，已标注待核"）。
