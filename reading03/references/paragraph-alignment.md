# 段落切分与对齐（Paragraph Alignment）

## 目标
长文跨页、跨栏、跨章节时**不漏段、不重复、不错位**，段号与原文一一对应，支持逐段定位回看与修改。

## 切分规则
按语义边界切分，每类各自成段，不把不同功能块混在一段里：
- 标题（Title）
- 摘要（Abstract）及其小标题
- 章节标题（Section / Subsection heading）
- 正文段落（每个自然段）
- 图注（Figure caption）、表头与表注（Table header / note）
- 公式及其编号（Equation + number）
- 参考文献条目（References，如任务要求翻译）

## 段号约定
`source_id` 稳定且可读：`t-001`（标题）、`a-001`（摘要）、`p-001`…（正文）、`f-001`（图注）、`tb-001`（表头）、`e-001`（公式）、`r-001`（文献）。段号按原文顺序递增，跨页不断号。

## 对齐输出
每个段落一条记录：
```json
{"source_id":"p-003","source_text":"...","translation":"...",
 "location":"p.4 左栏 ¶2","rationale":"...","untranslated":[]}
```
`location` 至少写到"页码 + 段落序号"，跨栏时补"左/右栏"。

## 长文续译的上下文携带
逐段翻译时携带：
1. 前一段末尾 1–2 句（处理跨段指代，如 "This effect" 指上段）
2. 已锁定的术语表（见 terminology-lock.md）
3. 当前章节标题（判断段落在论证中的位置）

不要孤立地逐段翻，否则指代对象会错。

## 对齐校验（align_paragraphs.py）
检查三类错误：
- **漏段**：原文有 `source_id`，译文结果里没有
- **重复**：同一 `source_id` 出现多次
- **错位**：译文 `source_id` 顺序与原文顺序不一致（可能是段落串行）

输出 `coverage`（覆盖率）、`missing`、`duplicate`、`out_of_order`，任一非空则判对齐失败。

## 常见失败
| 失败模式 | 表现 | 处理 |
|---|---|---|
| 跨页漏段 | 页尾段被截断丢弃 | 以原文段号为准逐页核对 |
| 跨栏错位 | 先译右栏后译左栏 | 按版面阅读顺序重新编号 |
| 图注并入正文 | 图注丢失或与正文混排 | 图注单独成段 |
| 表头当正文译 | 表格结构丢失 | 表头单独成段，保留行列对应 |
