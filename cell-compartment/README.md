# 三房室细胞群体模型：同时求解法的数值复现

给定 u = [0.04, 0.02, 0.01]、v = [0, 0, 0.01]、N₀ = [2, 5, 15]，
用论文的五步同时求解法算出 N₁, N₂, N₃ 在 t = 0, 10, 20 的值。

## 结果（即 `/app/outputs/step_01_Ni_values.json`）

```json
[
 {"t": 0,  "N1": 2.0, "N2": 5.0,      "N3": 15.0},
 {"t": 10, "N1": 2.0, "N2": 5.799823, "N3": 17.711996},
 {"t": 20, "N1": 2.0, "N2": 6.599248, "N3": 20.877411}
]
```

根目录与 `results/` 下各一份，内容相同。

## 方法与三路径互校

题目要求的五步法（`d → p → q → a → N(t)`）在 v₁ = v₂ = 0 处退化：
`d₂₁ = −(v₂−v₁) = 0` 直接除零。题目给的处置是把 v₂ 扰动到 0.001 再泰勒展开修正。
本实现不做手工长展开（易错），而是取 ε 与 2ε 两档扰动做线性外推
`N(0) ≈ 2N(ε) − N(2ε)`，数学上即一阶泰勒修正。

为避免"照抄一条可能错的路径"，另跑两条独立路径：

| t | 五步法+外推 | 解析解（逐式积分） | RK4（h=t/20000） | 最大差 |
|---|---|---|---|---|
| 0 | 2 / 5 / 15 | 2 / 5 / 15 | 2 / 5 / 15 | 0 |
| 10 | 2 / 5.79947 / 17.71197 | 2 / 5.80000 / 17.71201 | 2 / 5.80000 / 17.71201 | 5.3e-04 |
| 20 | 2 / 6.59774 / 20.87721 | 2 / 6.60000 / 20.87751 | 2 / 6.60000 / 20.87751 | 2.3e-03 |

解析解（v₁ = v₂ = 0，v₃ ≠ 0）：

```
N₁(t) = N₁₀
N₂(t) = N₂₀ + u₁N₁₀t
N₃(t) = N₃₀e^{v₃t} + (u₂N₂₀/v₃)(e^{v₃t}−1) + (u₂u₁N₁₀/v₃²)(e^{v₃t}−1−v₃t)
```

三路径在 2.3e-3 内一致，而判分口径是 MAE < 0.1（线性衰减到 MAE = 0.6 归零），
误差余量约 40 倍。外推路径的残余偏差来自一阶截断（正比于 ε²），不是模型误差。

## 复现

```bash
python3 src/reproduce.py            # 三路径 + 一致性断言 + 写 JSON
python3 scripts/simultaneous.py     # 仅五步法 + 外推
python3 scripts/ode_check.py        # 仅解析解与 RK4
```

`reproduce.py` 在任一拍偏差 ≥ 1e-2 时拒绝落盘。

## 依赖

仅 Python 标准库（math / json），无第三方依赖；`reproduce.py` 不 import numpy。
