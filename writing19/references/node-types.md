# 六类节点：判定细则与易混边界

一条句子只归一类。归不进去的，要么是装饰句（不进图），要么该拆成两个节点。

## 1. question（研究问题）

**收**：显式问句、"we investigate/aim of"、明写的缺口（remains unclear / knowledge gap /
尚未见报道）。
**不收**：泛泛的重要性（"具有重要意义"）、作者的愿望（"我们希望"）。

边界：
- "低温下电导下降是快充的主要障碍" → 这是**背景+缺口**，若案例任务是"找出研究问题"，
  可归 question；若已有显式问句，则它归 task 或丢弃。
- "本文提出一种新方法" → 不是问题，是方法或结论的开头。

## 2. method（方法）

**收**：材料与配比、仪器型号、流程步骤、测试标准、参数（温度/压力/时间）。
**不收**：方法的意义（属于 conclusion）、方法的结果（属于 evidence）。

边界：
- "采用两步法合成" → method。
- "两步法使产率提高 12%" → evidence（有数值和比较）。
- "该方法优于传统方法" → conclusion（无数据的判断），或 evidence（若前句给了数）。

## 3. evidence（证据）

**收**：带单位的数值、图表引用、误差与显著性、对照结果。
**不收**：没有出处的定性描述（"效果显著"）。

判定硬条件（至少一条）：
- 含数值 + 单位（`3.8 mS/cm`、`0.17`、`41%`）
- 含 `Fig./Table/图 N/表 N` 引用
- 含对照表述且给了两端数值（"从 41% 提升到 68%"）

边界：
- "相对密度最低达 0.17" → evidence（数字）。
- "作者认为密度降低源于成核增强" → conclusion（解释）。
- "密度降低 40%" 与 "减重 40%" 是**两个口径**，不能合并成一个节点；若原文混用，
  建两个节点并在关系里标 conflict。

## 4. conclusion（结论）

**收**：作者对结果的解释、机制、外推、"首次/唯一"类主张。
**不收**：结果本身的复述（属于 evidence）。

边界：
- "溶剂化结构由接触离子对转向聚集体" → conclusion（机制）。
- "因此该电解质适合快充" → conclusion（外推），必须挂回支撑它的 evidence 节点。
- "首次证明 X" → conclusion，且 `level=summary`；若原文没给检索范围，
  在 note 里写"未给检索范围，不能作为事实引用"。

## 5. limitation（局限）

**收**：明确写出的边界、未做的实验、样本量不足、条件限制。
**不收**：客套话（"仍需进一步研究"）——除非它指明了缺什么。

边界：
- "未给出长循环数据" → limitation（明确了缺什么）。
- "未报告低温沉积形貌" → limitation。
- "未来将研究其它材料" → task（下一步动作），不是局限。

## 6. task（任务）

**收**：明确的后续动作、待办、里程碑、必须满足的条件。
**不收**：作者的期望、泛泛的展望。

边界：
- "需在 −40 °C 复核" → task。
- "换瓶级高黏度料复现" → 若原文只说"换料会提高熔体强度"，这是**推断出来的任务**，
  `level=inference`，且必须进 uncertainty。

## 装饰句清单（直接丢弃）

- "近年来受到广泛关注"
- "随着…的发展"
- "具有重要意义"
- "本文结构安排如下"
- 纯过渡：`as previously said` / `it is worth noting that` / `详见下文`

这些句子进图只会让图变长，不会让人更懂。
