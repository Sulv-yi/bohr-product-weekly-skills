# 层级、粒度与关系：规则与反例

## 一、层级

```
根：材料主题（≤34 字）
├─ 一级：类型分支（≤6 个，缺类不补）
│   ├─ 二级：子主题（≤7 个）
│   │   └─ 三级：具体判断（≤7 个）
```

**深度 ≤4（含根）**。第 5 层意味着你在做正文复述。

反例（深度 5）：
```
rPET 发泡
└ 证据
  └ 密度
    └ PET_C
      └ 220 ℃
        └ 0.17          ← 这一层的"0.17"应该写进上一层的标题
```
改法：`彩色料 220 ℃ 下最低 0.17`，删掉两级。

## 二、扇出与粒度

**扇出 ≤7**。超过说明这一层没归并。

反例（一个父节点下 11 条）：
```
证据
├ 相对密度降 40%
├ 泡孔 2 μm
├ 泡孔 5–18 μm
├ 减重 40%
├ 密度 0.17
├ 密度 0.20
├ MFI 46.70
├ 黏度 0.70–0.80
├ 帽体 1.26
├ 电导 3.8
└ 阻抗 0.8
```
改法：先分「密度类 / 泡孔类 / 流变类」三个子主题，再各挂 2–4 条。

**同级标题长度离散度 ≤0.55（CV）**。一条 8 字、一条 40 字，读起来就散了。

反例：
```
- 密度降了           (5 字)
- 彩色回收料在 220 ℃、30 MPa 饱和条件下相对密度最低达 0.17   (33 字)
```
改法：统一到 12–20 字，细节进 note。

## 三、关系七型

| 类型 | 判据 | 反例（不该连） |
|---|---|---|
| `cause` | 有明确因果词，且两端都在图里 | 两段相邻就画"导致" |
| `depend` | B 的成立需要 A（条件/前提/先后） | 把"方法"和"结论"画成依赖 |
| `contrast` | 同指标不同条件或不同料 | 两个不相关的数 |
| `sequence` | 时间或步骤先后，有先后词 | 把并列的两条画成先后 |
| `cite` | 有 `[n]` 或 `(Author, year)` | 同一段的两句互引 |
| `support` | 一条证据支撑一个判断 | 同父的两条证据互相"支撑" |
| `conflict` | 两个数/两个说法对不上 | 不同指标之间的差（那是对比，不是冲突） |

**每条关系必须有 evidence**。说不出依据的关系不要画——图上多一条虚线，
读者就少信一分。

## 四、结构性关系的画法

- 父子关系表达"归属"，不用另外画 `support`。
- 只有**跨分支**的关系才画虚线：证据→结论、局限→结论、方法→证据。
- 同一父节点下的兄弟关系默认不画（读者靠位置就能看懂）。

反例（把所有兄弟都连成 support）：
```
证据 A ⟷ 证据 B ⟷ 证据 C     ← 20 条线，读不出谁是主
```
改法：只连"谁支撑谁"的那一条，其余靠层级表达。

## 五、根节点

根节点写**材料主题**，不写"思维导图""分析结果"。

反例：`材料主题（待按案例任务改写）`
正例：`rPET 打印件发泡：减重与保形`

根节点也要有 evidence（通常是标题页或摘要首句），否则整张图没有锚点。
