# 最小调用示例（示意，不是正式案例结果）

> 下面是一份 6 句的玩具材料，用来说明接口与完整流程。
> 输出为示意，**不冒充平台固定案例的结果**。

## 输入：`material.md`

```markdown
<!-- page 1 -->
# 低温电解质的离子电导

## 摘要

低温下离子电导下降是锂金属电池快充的主要障碍。本文用 1.2 mol/L 双氟磺酰亚胺锂
溶于氟代碳酸酯，在 −20 °C 下测得离子电导 3.8 mS/cm。相比常规碳酸酯电解液，
该体系的电导保持率从 41% 提升到 68%。作者据此提出溶剂化结构从接触离子对向
聚集体转变的机制。但未给出长循环数据，且未报告低温下的锂沉积形貌。

<!-- page 2 -->
## 结果

在 −20 °C 时，3.8 mS/cm 的电导对应 0.8 Ω·cm² 的界面阻抗。
```

## 调用

```bash
python3 scripts/mm_scaffold.py --in material.md --out work --title "低温电解质"
python3 scripts/mm_run.py --material material.md --work work --out output --case-id demo
```

## 中间产物：`work/blocks.md`（节选）

```
- `P1-S1` [标题] 低温电解质的离子电导
- `P1-S2` [标题] 摘要
- `P1-S3` [问题] 低温下离子电导下降是锂金属电池快充的主要障碍
- `P1-S4` [方法] 本文用 1.2 mol/L 双氟磺酰亚胺锂溶于氟代碳酸酯
- `P1-S5` [证据] 在 −20 °C 下测得离子电导 3.8 mS/cm
- `P1-S6` [证据] 相比常规碳酸酯电解液，该体系的电导保持率从 41% 提升到 68%
- `P1-S7` [结论] 作者据此提出溶剂化结构从接触离子对向聚集体转变的机制
- `P1-S8` [局限] 但未给出长循环数据，且未报告低温下的锂沉积形貌
- `P2-S1` [证据] 在 −20 °C 时，3.8 mS/cm 的电导对应 0.8 Ω·cm² 的界面阻抗
```

`hints` 只是句式线索。P1-S3 虽然是"障碍"句，但它在摘要里承担的是研究背景，
Agent 应按案例任务判断它是 `question` 还是 `task`。

## 这个例子要说明的三件事

1. **接口只有两个入口**：材料文件 + `case.json`（可选），输出目录固定。
2. **每个节点都带 `P页-S句`**：读者能顺着编号回原文，不需要信任图。
3. **关系不是装饰**：`conflict` 那条把"机制结论"和"缺长循环"的张力摆在图上，
   这是导图比摘要更有用的地方。
