# 证据定位与不确定性标注

## 证据格式

每条结论附一条或多条证据：

```json
{
  "page": 3,
  "block_id": "p003-b012",
  "bbox": [72.4, 158.2, 540.1, 176.8],
  "quote": "原文逐字片段，必须能在该块的 text 中找到"
}
```

- `page` 为 PDF 物理页（1-based）。
- `bbox` 为 `[x0, y0, x1, y1]`，单位 pt，来自提取块。
- `quote` 必须逐字来自原文；翻译/改写类结果也要附原文引用作为依据。
- 校验脚本会检查 quote 是否出现在对应块的 text 中，出现不一致必须修正。

## 三类边界，分开写

| 类型 | 含义 | status 影响 |
|---|---|---|
| `not_reported` | 材料里根本没有该信息 | 不影响 |
| `undetermined` | 材料里有但读不出/有冲突/图像无法取值 | partial |
| `conflict` | 材料内部两处说法不一致 | partial |

每条写清：`item`（哪项）、`type`、`reason`、`page`/`block_id`（若有）。

## 运行状态 status

- `success`：任务完成，证据齐全。
- `partial`：完成主要部分，但有明确限制或不确定项（需在 uncertainty 说明）。
- `blocked`：无法开始，如加密无密码、文件损坏（需在 uncertainty 说明原因和人工接管点）。
- `unanswerable`：材料充分判断但确实无法回答（需在 uncertainty 说明依据）。

## 禁止

- 不得用模型常识补全原文没有的数据、单位、结论。
- 不得把示意图当实验数据、把他人结果当本文结果。
- 不得编造运行日志、测试成绩或评分。
