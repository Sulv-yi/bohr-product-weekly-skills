# 表格结构还原

目标：把 PDF 里的表格还原成可直接比对的结构（Markdown 或结构化 JSON），行列归属准确。

## 判定表格

- 有文字层：同一 y 带上出现多个 x 间隔明显的块，或块间存在规则竖线 → 表格区域。
- 无文字层：图像中检测横竖线 → 图像型表格，进入 OCR 分支。

## 行列与合并

1. 收集所有单元格 bbox，按 y 聚成行（容差约字高的 1/3），按 x 排序列。
2. 跨行合并：某单元格 bbox 高度覆盖多个行 → 在结构化输出里标记 `rowspan`。
3. 跨列合并：宽度覆盖多列 → 标记 `colspan`；Markdown 用合并后的文本放首列并在 uncertainty 里说明。
4. 多层表头：前 1–3 行为表头，按层级展平为复合列名，如 `指针/地址` → `地址总线/指针`。
5. 单元格内换行保留，不拼成一句；数值与单位分离但都保留。

## 跨页续表

- 下一页顶部出现相同表头或列数一致的块 → 续表，合并行，注明 `pages: [n, n+1]`。
- 表注（"Table 3. ..."）作为独立块，含在 sources。

## 证据与不确定

- 每个单元格可附 `{page, bbox}`；关键数值必须能指回原文。
- 无法确定合并关系或单元格数值读不清 → 用 `〔无法识别〕` 占位并写入 uncertainty，**不得猜数**。
- 示意图（架构图/流程图）不要当实验数据表处理；按结构元素识别，不解读数值。
