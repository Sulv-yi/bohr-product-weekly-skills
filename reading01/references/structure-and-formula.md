# 章节结构、题注、公式与参考文献

## 章节层级

- 标题特征：字号大于正文、加粗、编号模式（`1` / `1.1` / `一、` / `Chapter` / `Section`）。
- 建立层级树：Document > Section(1..n) > Subsection > Paragraph；每个段保留所属章节路径，如 `3.2.1`。
- 摘要（Abstract/摘要）、关键词、致谢、附录、参考文献作为具名节单列。

## 图表与题注

- 题注正则：`^(Fig(ure)?|Table|图|表)\s*\d+` 或含 `No.`；紧邻图像/表格块。
- 图表编号与正文引用必须一致：正文提到"图 3"时，证据指向题注为"图 3"的块；编号对不上写入 uncertainty。
- 图表位置（page + bbox）记入 sources。

## 公式与特殊字符

- 行间公式：居中、独占一行、两侧有空白 → 独立块，标记 `formula`，保留编号 `(1)`。
- 行内公式：保留在句中，不拆断。
- 上下标、希腊字母、求和/积分符号优先用 Unicode 原样保留；无法还原时用 LaTeX 近似并在 uncertainty 标注。
- 公式编号与正文引用对齐；符号失真（如 `α` 被识别成 `a`）写入 uncertainty。
- 本 Skill 只做结构保真，不解释公式科学含义。

## 参考文献

- 以 `[1]` / `(Author, Year)` 等模式识别，保留编号与原文格式。
- 正文引用 `[3]` 关联到参考文献第 3 条；缺号或冲突写入 uncertainty。
