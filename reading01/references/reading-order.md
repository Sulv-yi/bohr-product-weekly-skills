# 阅读顺序与版式规则

目标：让输出顺序等于人眼按版面阅读的顺序，不串栏、不错行、不漏段。

## 判定栏目

1. 取一页所有文本块的 bbox 中点 x，做聚类。出现两个明显峰值且中间有空白带 → 双栏；三个以上 → 多栏。
2. 单栏页按 `top` 升序；双栏页按「先左栏 top 升序，再右栏 top 升序」；跨栏元素（横跨两栏的标题/图表/公式）单独识别并插回它所在的纵向位置。
3. 栏目归属写在块的 `column` 字段（0=跨栏，1=左，2=右…），便于后续引用。

## 跨栏与跨页

- 跨栏标题：宽度 > 页宽 60% 且字号明显大 → 视为跨栏，按 y 位置插入。
- 跨栏图表：题注含 "Fig"/"Table"/"图"/"表" 且宽度跨栏 → 作为独立块，位置取题注 y。
- 跨页续接：若页末块以逗号/连词/未闭合括号结尾，且下一页首块首字母小写或接上句 → 合并，并在 sources 里同时保留两页 block_id。
- 摘要与关键词常为跨栏，位于标题之后、正文之前，不要丢。

## 页眉页脚与脚注

- 位于页面上/下 8% 区域、每页重复出现的短文本 → 页眉/页脚，从正文剔除；若任务要求完整提取，单独归入 `header_footer` 字段。
- 脚注标记（上标数字）在正文、注释在页底 → 用标记号关联，不放进正文流。
- 参考文献单独成节，编号保留，不混入正文段落。

## 输出检查

- 抽查正文首段与末段是否完整、是否出现两栏句子拼接。
- 章节编号是否连续（1, 1.1, 1.2, 2…）；断裂说明漏段或串栏。
