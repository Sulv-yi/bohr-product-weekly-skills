# 参数与正文对齐（Parameter Alignment）

## 目标
正文里出现的每个参数取值、数据集版本、训练/评测条件，都必须能在要素表里找到来源；防止"为了段落顺畅补出的数值"。

## 三类错误

### 1. 无来源数值（fabricated_value）
正文写"学习率设为 1e-3"，但参数表里没有 lr 这一项，或来源为空 → 失败。这是最严重的一类，直接违反"写得准"。

### 2. 数值串位（value_mismatch）
正文写 1e-3，参数表记的是 1e-4 → 失败。常见于改稿后正文没同步。

### 3. 覆盖不全（uncovered_parameter）
参数表里的关键参数（影响复现的，如 seed、batch size、epochs、版本）在正文完全没提 → 警告，通常要补写。

## 校验（align_params.py）
输入正文要素表与参数表：
- 抽取正文中的所有数值串（含科学计数、单位）
- 对每个正文数值，检查参数表中是否有等值项且 `source` 非空
- 无匹配 → `fabricated_value`；有小概率是单位换算，标 `needs_confirm` 交人工

## 人工确认项
- 正文用"约""左右"描述的数值：无法精确对齐，标 `needs_confirm`
- 单位换算（如 0.0001 = 1e-4）：脚本可识别等值，但作用对象要人工确认
- 区间/范围：核对上下限都来自材料

## 写法建议
正文中每个关键数值后紧跟来源标注（如"学习率 1e-4（见 config.yaml）"），既方便回查，也降低评审核对成本。参数表单独成表，正文与表数值一一对应。
