# 方法与实验设置（示例 baseline 输出，未加载 Skill）

> 示例说明：本文件用于演示 `eval/compare_ab.py` 的对照算法，模拟**不加载 Skill** 时的典型输出；不是平台对照结果，材料亦为虚构演示内容。

本文采用点云语义分割模型进行实验。模型由编码器和解码器组成，输入点云经过下采样后送入网络，输出每个点的语义类别。训练时使用 AdamW 优化器，学习率设置为 3e-4，训练若干轮后在验证集上评估。

实验中使用了公开数据集，按照常规比例划分为训练集、验证集和测试集。为验证方法有效性，与 PointNet++ 和 RandLA-Net 进行了对比，结果表明本文方法取得较好效果。

实验环境为服务器，使用 GPU 加速。评价指标为 mIoU。由于时间与条件限制，本文方法存在一定局限性，未来将进一步改进。
