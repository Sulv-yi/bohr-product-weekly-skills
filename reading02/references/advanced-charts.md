# 对数轴与统计图的补充规则

## 对数轴（log=true）

- 标定的 val 填真实数值（如 0.001 和 1000），脚本在 log10 空间插值。
- 判别方法（Agent 视觉）：刻度间隔均匀但数值为 1, 10, 100…（或 0.1, 1, 10）→ 对数轴。
  均匀间隔的均匀数值 → 线性轴。拿不准时两种都算一遍，取刻度残差小的。
- 输出不确定度同样在 log10 空间报（如 ±0.03 dex），不换回线性。
- 双对数图（x、y 都 log）：两边都设 log=true，叠加自查图仍然是像素空间，不受影响。

## 统计图（柱状/箱线/误差线）

- mode=dark 逐列扫描对柱状图同样有效：柱顶位置就是该列最长暗段的顶端。
  输出的是"每列最高点"，柱高 → 数值的换算走同一套标定。
- 误差线（顶端的横帽）：同列会出现两段短横线，脚本记入 dropped_segments，
  Agent 读误差线端点数值写进 direct_readable（如 "均值 3.2 ± 0.4，误差线帽位于 y_px 210/286"）。
- 显著性标记（*、**、ns）：文字，Agent 读；不做像素分析。位置记成 (x_px, y_px)。
- 箱线图：中位数线、箱体、须线是不同长度的暗段，按列解析可分别提取，
  但需要 Agent 先指认各段含义——脚本输出的分段结果在 CSV 的 dropped_segments。

## 多子图（(a)(b)(c)）

- 对每个子图独立跑一遍 c2d_axes（整图跑会误把子图间距当轴线）。
  用 --thresh 提高阈值（如 100）可减少子图间浅色分隔的干扰。
- 每个子图一份 calib/CSV，文件名带子图编号：fig2b-calib.json, fig2b-curve.csv。
- 跨子图结论（如 "图(a) 的峰值对应图(b) 的拐点"）属于 inference 区，要写明两个子图的证据路径。

## 比例尺（显微图）

- 比例尺是图内一段已知长度的线：Agent 读出标注值（如 "2 μm"），
  脚本量出该线段像素长（Agent 给两端点大致位置，脚本精确拟合端点），
  换算系数 = 标注值 / 像素长。这个系数替代轴标定，其余流程不变。
- 显微图目标尺寸统计（数量、直径分布）：mode=color 按结构染色提取，
  每个连通域的等效直径 = sqrt(像素数) × 换算系数（纯 PIL 用扫描线连通域，见 references/edge-cases.md）。
