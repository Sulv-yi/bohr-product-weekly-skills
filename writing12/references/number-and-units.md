# 数字与单位：不许"顺手改"

## 1. 五类必查数字

| 类别 | 原文例子 | 译错形态 | 正确做法 |
|---|---|---|---|
| 测量值 | `62.4 MPa` | 62 MPa | 原样，小数位不动 |
| 百分数 | `78.3%` | 78% | 原样；`percentage point` 与 `%` 分清 |
| 统计量 | `p = 0.012` | p=0.01 | 原样；`p<0.05` 不要写成 `p=0.05` |
| 样本量 | `n = 24 per group` | 24 例 | 保留 `n =` 与"每组" |
| 量级 | `3.5 million` | 3.5 万 / 350 万 | 350 万（=3.5×10⁶） |

## 2. 中英量级换算

| 英文 | 值 | 中文写法 |
|---|---|---|
| thousand | 10³ | 千 |
| million | 10⁶ | 百万 / 万（350 万 = 3.5 million） |
| billion | 10⁹ | 十亿 / 亿（12 亿 = 1.2 billion） |
| trillion | 10¹² | 万亿 |

换算后**必须是同一个值**：`3.5 million` → `350 万` 正确；`3.5 万` 错了一个数量级。
脚本按值比对（容差 0.5%），`3.5 万` 会同时进 `number_transfer_rate` 的漏项和 `magnitude_errors`。

## 3. 有效数字

- `0.037` 不能写 `0.04`；`1.20` 与 `1.2` 在报告有效数字时含义不同，**保留原位数**。
- 原文写 `≈` / `about` / `approximately` 时，译文要保留"约"，不要因为数字是整数就写成确定值。
- 原文写范围 `10%–40%`，译文保留区间与连接号，不要写成"10% 到 40% 之间"再顺手取整。

## 4. 单位

- SI 单位不翻译（`MPa`、`μm`、`wt%`），中文里也不改写成"兆帕"除非目标期刊要求。
- `wt%` / `vol%` / `mol%` 三者不可互换；`mg/kg` 与 `mg·kg⁻¹` 是同义写法，保持原样即可。
- 温度：`°C` 与 `℃` 视为同值；`K` 与 `°C` **不可**直接替换。
- 单位缺失时不要补：`62.4` 后面没单位，就在 `uncertainty` 记 `unit_missing`。

## 5. 数字与图表对不上

原文自身矛盾（正文 62.4 MPa、图注 62 MPa）时：**照原文译**，保留两处原值，
在 `uncertainty` 写 `source_inconsistent` + 两个值 + 所在段号。不要替作者"统一"——
那是学术不端，也不是译者的权限。

## 6. 检查方式

`number-audit.csv` 一行一个数值：

```
seg,raw,value,unit,status
P03,62.4 MPa,62.4,MPa,landed
P10,12.4,12.4,-,landed
```

`status` 只有三种：`landed` / `MISSING` / `MAGNITUDE_ERROR`。
`MISSING` 大多是取整或省译；`MAGNITUDE_ERROR` 一定是量级换算错了。
