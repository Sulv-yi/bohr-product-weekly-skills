# 语域与风格：学术、可读、不生硬

## 1. 三条不能碰的底线

1. **不加宣传口吻**：`显著提升`→ 保留"显著"只在原文有 statistical significance 时；
   `重大突破`、`国际领先` 这类词在没有原文依据时一律不加。
2. **不口语化**：`我们搞出来一个`、`结果挺不错` 不进学术译文；口语化在摘要/正文里都算错。
3. **不逐字硬译**：`It is worth noting that` 直译"值得注意的是"在中文学术稿里可用，
   但每段来一次就成了噪音；`In this study, we` 直译"在本研究中，我们"可省"我们"。

## 2. 中文学术稿的句式偏好

| 英文形态 | 生硬直译 | 通顺译法 |
|---|---|---|
| 长被动链 `was measured by … and was obtained from …` | 被…测量且被…获得 | 以…测定，由…获得 |
| `Here we` | 这里我们 | 本研究 |
| `However,` 句首 | 然而， | 然而，（可留，但不必每段都用） |
| `As shown in Fig. 2a` | 如图 2a 所示 | 如图 2a 所示（保持） |
| `plays an important role in` | 扮演重要角色 | 对…有重要作用 / 影响… |

通顺化不等于改写：句子结构可调，**信息量与断言强度不能变**。

## 3. 术语与修辞的关系

- 术语用锁定译法，哪怕读起来拗口（`微型计算机断层扫描`），也不要为顺口改成`微型CT`——
  除非术语表里 `微型CT` 就是锁定值。
- 同一段里同一概念不要换称呼求变化。中文写作课教的"避免重复"在术语上不适用。

## 4. 图表与公式周边的文字

- 图注、表头、坐标轴标签、图例：优先短、平行、可扫读；`(a)` `(b)` 子图标记保留。
- 公式不进正文行内改写，编号 `(1)` `(2)` 原位保留。
- 单位与量符号之间按原文留空格（`62.4 MPa`），中文全角标点用于句子层。

## 5. 双语对照的可读性

- 每段 `EN` 在上、`ZH` 在下，段号独立成行，便于 diff；
- 不在段内混排双语（一句英一句中），那样无法逐段改稿；
- 译文段内可用中文全角标点，原文段保持英文半角——两边各自符合自身语言规范。

## 6. 风格与评分的关系

风格问题不触发硬门槛（脚本量不出"生硬"），但影响"使用增益"里的可编辑性判断：
读者能不能直接在你的译稿上改，取决于句段是否对应、术语是否统一、标记是否在原位。
**先把四把尺做对，再谈润色**——顺序反了，润色会把对齐改坏。
