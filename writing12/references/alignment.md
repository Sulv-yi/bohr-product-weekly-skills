# 段级对齐：为什么按段号而不是按句子

## 1. 段号是对齐主键

双语对照稿的最小单元是"段"，不是"句"也不是"章"。理由有三：

1. 作者改稿以段为单位（"这段结论改一下"），以句为单位会切碎上下文；
2. 段号稳定：句子在同一次修订里会被合、拆、调序，段号通常不动；
3. 所有核查（术语、数值、标记、边界）都要落到某个区间，段号是唯一横跨四类检查的坐标。

格式固定为：

```
## P07

EN: The increase in modulus may be associated with …

ZH: 模量的提高可能与刚性陶瓷相限制聚合物链段运动有关…
```

`EN` / `ZH` 两种行前缀必须保留——解析器靠它分段；写成两栏表格也可以，但要有段号列。

## 2. 允许的合并与禁止的合并

| 情况 | 处置 |
|---|---|
| 原文两个短句合成中文一句 | 保留在同一 `Pxx` 内，允许 |
| 原文一段拆成中文两段 | 仍放在同一 `Pxx`，用 `ZH` 行内换行表示，不允许新增 `Pxx` |
| 原文相邻两段合成一段 | **禁止**：会产生"漏译段"，覆盖率立刻下降 |
| 原文被删（作者要求压缩） | 该 `Pxx` 标 `omitted_by_request` 并写明依据，不静默删除 |

## 3. 段落顺序

`order_preserved` 检查段号是否按升序出现。调序在学术稿里几乎总是错的：
读者按图号、表号、引用号追读，调序会让"如上所述"变成"如下所述"。

## 4. 标记的跨语言等价

中英对照里标记会换"外壳"，判断保留要看**本体**而不是字面：

| 原文 | 译文 | 判定键 |
|---|---|---|
| `[12,13–15]` | `[12,13–15]` | `cite:12,13,14,15` |
| `(Zhang et al., 2021)` | `（Zhang et al., 2021）` | `auth:zhangetal.,2021` |
| `Fig. 2a` | `图 2a` | `fig:2a` |
| `Table 1` | `表 1` | `tbl:1` |
| `$E = \sigma/\varepsilon$` | `$E = \sigma/\varepsilon$` | `fx:E=\sigma/\varepsilon` |
| `^1` | `^1` | `fn:1` |

脚本按这张表归一，所以「`Fig. 2a` → `图 2a`」算保留，「`Fig. 2a` → `图 2`」算丢失。

## 5. 图表题注单独处理

题注常被单独交给别人改，因此：

- 题注也占一个 `Pxx`（如 `P05` 若为图注），不要合并进正文段；
- 题注里的术语必须在术语表里有对应条目（`section: caption`）；
- 题注中的 `n =`、误差棒说明、统计符号一并保留。

## 6. 对齐失败的三种信号

1. `pair_coverage < 95%`：有段没译，或合并了两段；
2. `order_preserved = false`：段号乱序；
3. `marker_keep < 90%`：标记在翻译过程中被"顺手删了"。

三条同时看，能区分"漏译"和"重排"两种完全不同的返工方式。
