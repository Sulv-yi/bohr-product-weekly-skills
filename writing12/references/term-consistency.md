# 术语一致性：从抽取到锁定

## 1. 什么时候必须建表

出现下列任一情况就要建表，而不是"边译边统一"：

- 同一名词在原文出现 ≥2 次；
- 材料跨章节（摘要 + 方法 + 图注 + 附录），而图注常被单独交给别人改；
- 存在缩写（`PLA`、`BaTiO3`、`d33`），且首次出现要给全称；
- 同一英文词在不同学科译法不同（`scaffold`、`matrix`、`template`、`module`）。

## 2. 抽取三类候选

| 类型 | 抓法 | 例子 |
|---|---|---|
| 多词名词短语 | 连续 2–4 个实词，出现 ≥2 次 | `compressive modulus`、`fused deposition modelling` |
| 缩写 | 全大写 2–6 字母，或 `XxxYyy` 驼峰 | `PLA`、`BaTiO3`、`micro-CT` |
| 符号量 | 希腊字母 + 下标、单位组合 | `d33`、`E = σ/ε`、`wt%` |

## 3. 锁定规则

1. **一义一译**：同一 `en` 在全篇只允许一个 `zh`。表里出现两行不同 `zh` → `term_conflict`，脚本直接拦。
2. **主译从学科**：`scaffold` 在骨组织工程是"支架"，不是"脚手架"；`template` 在分子生物学是"模板"，
   在材料学可能是"模板剂"。判断依据是材料里同现的词（`porosity`、`osteoblast`、`implant`）。
3. **缩写首现给全称**：`聚乳酸（PLA）`。后文一律用缩写，不要"聚乳酸(PLA)"与"PLA"混用。
4. **图注与正文同表**：图注是最容易被单独改的地方，锁表时必须把 caption 一起纳入。
5. **禁用写法入表**：把机器翻译常见错译写进 `variants`（`脚手架`、`孔隙度`、`抗压强度`），
   脚本会在译文里逐条抓出来——这比事后人工通读有效得多。

## 4. 漂移的四种典型形态

| 形态 | 例子 | 脚本能否抓到 |
|---|---|---|
| 换词 | 支架 → 骨架 / 脚手架 | 能（variants 命中） |
| 换词性 | 压电 → 压电性 | 能（variants 命中） |
| 缩写与全称混用 | 聚乳酸 / PLA 交替出现在同一段 | 部分（术语落地率下降） |
| 语序改写 | 压缩模量 → 模量（压缩） | 不能，需人工确认 |

第四种只能人工看。所以 `selfcheck.md` 里保留"术语→段号"清单，供逐段扫一眼。

## 5. 表怎么维护

- 术语表是**资产**，不是一次性产物：本篇译完把新增条目并回 `examples/term-table.json`，
  下一篇同领域直接复用。
- 每条带 `section`（`abstract` / `methods` / `caption` / `appendix`），
  便于在图注单独返工时只核对相关条目。
- 跨篇冲突时以"最新一篇的学科语境"为准，并在表里留一行备注说明改判理由。

## 6. 与其他检查的接口

术语表是 `term-audit.csv` 的输入，也是 `validate_result.py` 里 `term_coverage` 与
`term_variant_leak` 的唯一依据。表不全，这两项就会虚高——所以门槛挂在"表 ≥12 条"上。
