# 提示词 A3 · 条件与口径复核（在脚本结果之上做判断）

目的：脚本只能判"数值对不对、口径词在不在"，条件和对照臂要靠人读。

```
材料：evidence/claims.csv、evidence/corpus.csv、evidence/check.md（脚本判定结果）。

对每个 FAIL / CONFLICT 条目，回原文回答四问，写进 evidence/manual_verify.md：
1. 这条结论成立的条件是什么（压力、温度、材料、测试标准、样品形态）？
2. 同一个指标的另一个数出现在哪一段，是"条件不同"还是"口径不同"？
3. 这条结论的对照臂是谁？对照臂和实验臂在同一规格上吗（黏度、厚度、标准）？
4. 如果要把这条结论写进我自己的材料，准确的写法是什么（带限定的一句话）？

另外单独检查三件脚本判不了的事：
- 摘要里的比较级（better / outperform）有没有同条件下的证据；
- 同一物理量是否在不同段落换了口径（相对密度 / 密度 / 重量 / 体积膨胀）；
- "first / only" 类断言有没有给检索范围，没有就降级为"作者主张"。
```
