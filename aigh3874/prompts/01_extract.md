# 提示词 A1 · 抽取（保页码锚点）

目的：先把"可定位的原文"准备好。后续所有结论都要能指回这里。

```
用 pdf 抽取工具把论文转成 Markdown，要求：
1. 保留每页的 <!-- page N --> 分隔，页码按 PDF 物理页；
2. 不做摘要、不改写句子，只清理抽取残留（行末断词的软连字符、◦ -> °）；
3. 输出 materials/paper.md，并记录抽取命令与字节数到 materials/extraction.log。

抽完先回答三个问题：
- 全文多少页、多少字符？
- 摘要、结果与讨论、结论分别在第几页？
- 表 1、Fig. 8、Fig. 11、Fig. 12 各在第几页？
```
