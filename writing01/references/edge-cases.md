# 异常矩阵：整篇写作中的八类失败与处置

原则：**能判定就判定，判不了就标出来**。静默跳过、留空标题、编一个数值都是最坏处置。

| 情况 | 识别信号 | 处置 | status |
|---|---|---|---|
| 缺图注 | 正文有「（图 1）」但找不到对应题注 | 补题注（内容/样本量/误差棒含义）；补不出就把该处改为文字描述 | `partial` |
| 图表与正文冲突 | 正文数值与图面或表内不一致 | 以原始数据为准，改正文并在 uncertainty 记 `conflict` | `partial` |
| 缺原始数据 | 只有汇总表，没有逐样本记录 | 结果段只写汇总值，不写逐样本统计；`uncertainty` 标 `not_reported` | `partial` |
| 文献取不到全文 | 只有题录或摘要 | 该条只支撑摘要级论断；方法/样本量相关结论不得引它 | `partial` |
| 引用格式不认识 | 输入用 author-year 或 EndNote 域 | 统一转为编号制并保留原格式在 `changes` 说明 | `success`/`partial` |
| 材料超长 | 材料超出可处理量 | 先建索引再按节取用；未读部分写进 `uncertainty`，不假装读过 | `partial` |
| 材料自相矛盾 | 两处记录给出不同样本量或参数 | 列进 `uncertainty`（`conflict`），正文取更保守的一组并注明 | `partial` |
| 文件缺失/权限不足 | 路径不存在或读报错 | 不猜内容；`status=blocked`，写清缺什么、需要谁提供 | `blocked` |

## 其余常见情况

- **跨学科模板**：目标期刊模板要求与本清单不同时，以模板为准，并在 `changes` 里列出差异章节。
- **语言切换**：中文稿按中文字数计；英文稿按词 ×0.6 折算，同一份门槛适用于两种语言。
- **图表编号重排**：重排后必须回查正文所有提及，否则会出现「孤立题注」。
- **样本量为 1 或未做重复**：结果段照写，讨论段必须把「未重复」写成局限，不得升格为结论。
- **预算将尽**：先落已有章节 + 索引 + 参考文献，标 `partial`，再增量补；交空壳得 0 分。

## 不许做的三件事

1. 用留空标题骗过「章节齐备度」——空标题按字数判定，不得分，且会被 `selfcheck.md` 标出；
2. 把材料里没有的数值写成「约」「大约」蒙过去——数值可回溯率会把它列出来；
3. 把 `status` 从 `partial` 改成 `success` 绕过门槛。
