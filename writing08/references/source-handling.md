# 材料读取与边界处理

## 读取真实材料

- 打开 case.json 指定的真实文件，不从文件名/标签推断内容。
- PDF 有文字层：PyMuPDF / pdfplumber 提取，保留页码与章节。
- 无文字层：OCR 生成文字层副本（写到 /app/work），标注置信度，quote 标 `"source":"ocr"`。
- 多文件材料：建立 file_id → 文件名映射，sources 里用 file_id 引用。

## 边界处理

| 情况 | 处置 |
|---|---|
| 材料缺关键事实 | 不补造；写 uncertainty（not_reported）并标 partial |
| 材料内部冲突 | 两处都列，标 conflict，不擅自选一边 |
| 引用查不到原文 | 保留论断，标"引用待核"，不伪造元数据 |
| 目标期刊格式未知 | 用通用格式，uncertainty 说明 |
| 语言与 task 不一致 | 按 task 指定语言，术语保留原文 |
| 超长材料 | 优先读摘要/结论/相关工作/实验节，其余按需要检索 |

## 记录要求

每次材料处理动作记入 changes：读了哪些文件、用了什么后端、是否 OCR、哪些页/节被引用。
