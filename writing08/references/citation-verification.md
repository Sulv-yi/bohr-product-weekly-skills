# 引用核验清单

## 元数据三要素

每条引用必须有：**作者 / 年份 / 来源**（期刊/会议/预印本/URL）。缺一即标"元数据不全"，写入 uncertainty，不猜测补全。

## 核验步骤

1. **键一致性**：稿件中每个引用键（如 `[3]`、`(Author, 2020)`）在 sources 里有对应条目。
2. **反向覆盖**：sources 里的关键文献是否都在稿件中被引用（避免列而未用）。
3. **论断绑定**：每条引用是否紧跟它支撑的论断，而非堆在段尾。
4. **原文一致**：转述的结论、数值、适用条件是否与来源 quote 一致。
5. **编号连续**：数字编号引用是否从 1 连续、无跳号重复。
6. **格式统一**：全文用同一种引用格式（除非 task 指定其他）。

## 常见错误

| 错误 | 处置 |
|---|---|
| 引用了但 sources 无此项 | 补来源或删引用，标 uncertainty |
| 作者年份对不上 | 以原文为准修正，不改原文迁就稿件 |
| 一长段只挂一个引用 | 拆分成多个论断，各自绑定引用 |
| 引用堆在段末 | 移到对应论断后 |
| 虚构参考文献 | 严禁；删除并标"引用待核" |

## 自动化

运行 `scripts/citation_check.py` 做机器可查的部分（键覆盖、元数据完整性、编号连续），人工判断部分（转述是否准确）仍需逐条核对并在 changes 记录。
