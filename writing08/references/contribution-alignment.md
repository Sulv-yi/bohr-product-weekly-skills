# 贡献表述与证据对照

## 原则

每条贡献必须能在正文找到对应证据（方法节、图表、实验）。没有证据的"贡献"要么降级为定位描述，要么标为作者判断，不能夸大适用范围。

## 贡献清单格式

```json
{
  "claim": "提出……方法，解决……问题",
  "evidence": {"section": "3.2", "figure": "图2", "table": "表1"},
  "scope": "在……数据集/条件下验证",
  "source_ids": ["s-005", "s-011"]
}
```

## 三类贡献

| 类型 | 可写内容 | 证据要求 |
|---|---|---|
| 方法贡献 | 新模型/新流程/新机制 | 方法节 + 至少一个实验对比 |
| 资源贡献 | 新数据集/基准/工具 | 数据描述 + 规模与获取方式 |
| 发现贡献 | 新的实证结论 | 实验图表 + 统计或复现说明 |

## 常见夸大与修正

- 「显著提升」→ 写出具体提升数值与对比基线（来自表/图）。
- 「首次」→ 需有相关工作覆盖证明，否则改为"据我们所知"并列 uncertainty。
- 「适用于各类场景」→ 收窄到实际验证的场景。
- 「证明」→ 实验支持用"表明/显示在……条件下"。

## 自检

逐条问：这句话能不能指向一个具体的图、表、节或文献？不能就改或删。
