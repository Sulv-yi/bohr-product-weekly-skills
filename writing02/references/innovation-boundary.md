# 与已有方案的边界

这一节回答一个问题：**这个 Skill 到底补了什么，哪些事它不该做。**
只写有依据的比较；没有实测过的对象，不声称优于它。

## 1. 比较对象与适用位置

| 方案 | 擅长 | 在本任务上的缺口 | 本 Skill 的位置 |
|---|---|---|---|
| 基础 Agent（不加载 Skill） | 通用改写、语气调整 | 无成本地整段重写；限定强度、数字、引用容易在改写中丢失；无逐句记录 | 把这些约束变成可执行检查，而不是靠自觉 |
| 通用写作工具（语法检查类） | 拼写、语法、标点 | 不理解术语一致性、不区分因果与相关、不保留引用与图表指向 | 只借用其"硬错误"判据，不依赖它做语义决策 |
| 机器翻译工具 | 跨语言转换 | 直译腔、主语与信息重心错位；不维护术语表 | 中译英时用作对照参考，不作为产出 |
| 人工润色 | 语感、领域判断 | 成本高、不可批量、口径不统一 | 做前 80% 的确定性工作，把判断留给作者 |

结论：本 Skill 不与上述任一方案正面竞争"文笔"，它竞争的是**可核验性**——
润色后仍能证明"哪些没变、为什么改、改得对不对"。

## 2. 基础 Agent 难以稳定做到的三件事

1. **术语表驱动的全篇回扫**
   注入术语表后，对全文做一次反向扫描：每个术语的每种写法都要归一到唯一译法，
   并报告未覆盖的候选术语。基础 Agent 通常只在该句附近保持一致，跨章节会漂移。

2. **限定强度守恒检查**
   建立限定词强度序（`可能 < 往往 < 通常 < 表明 < 证明`），逐段比对原文与改文的强度分布。
   加强或削弱结论都会被检出。基础 Agent 在"让句子更流畅"时最容易无意中加强结论。

3. **改写与审校双通道**
   先改写、再以"只读审校者"身份回读改文，专门找：数字变了没、否定范围变了没、
   引用还对不对得上。两个通道用不同检查表，避免自我确认偏误。

## 3. 方法取舍（为什么这样做）

| 取舍 | 选择 | 理由 |
|---|---|---|
| 编辑粒度 | 分句级最小编辑 | 整段重写会让"改了什么"不可追溯，也让强度与数据更容易漂移 |
| 术语处理 | 先建表再改文 | 边改边定术语必然自相矛盾 |
| 不确定项 | 显式标注，不猜 | 猜错的事实比留空更难被发现 |
| 记录方式 | 原文/改文/类型/理由四元组 | 只有四元组齐备，第三方才能判断"这处该不该改" |
| 自评 | 用脚本算，不用文字说 | 文字自述无法复核，脚本可被同一输入重跑 |

## 4. 不声称的部分

- 不声称在文学性、创造性表达上优于人工润色。
- 不声称对未实测的学科（如临床、法律）同样有效；术语与文体规则需按学科替换。
- 不声称零人工：`manual_review_items` 允许非零，那是诚实缺口，不是失败。
