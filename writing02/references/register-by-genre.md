# 目标文体与语域规则

润色前必须确认目标文体。未指定时默认"期刊论文"，并在 uncertainty 中说明。

## 期刊论文（默认）

- 人称：避免第一人称单数；用 "we" 或被动语态，依目标期刊惯例
- 时态：方法用过去时，普遍结论用现在时，已发表结果用现在完成时
- 语气：客观、克制；避免宣传化与绝对化
- 禁止：`obviously`、`clearly`（除非有数据支撑）、`novel` 自评、`best`、`perfect`
- 允许适度的hedging，且必须保持原限定强度

## 学位论文

- 允许适度的第一人称（"本文"、"本研究"）
- 章节衔接可略显式，但不用口语化连接词
- 文献综述部分动词时态：已发表研究用现在完成时或现在时
- 保持导师/学校模板要求的格式

## 基金申请书

- 强调问题的重要性与方案的可行性，但不夸大
- "创新性"表述要有具体依据，不用空泛形容词堆叠
- 避免直译腔：中文"本人拟..."改为自然的英文研究计划语气
- 句子不宜过长；每个段落一个主张

## 审稿回复（Response to Reviewers）

- 逐条对应审稿意见，标清 Response / Change 标记
- 语气礼貌但专业；不卑不亢，不辩解式表达
- 明确写出"已修改之处"与"未修改及原因"；未采纳的意见要给出技术性理由
- 引用审稿人原话时逐字保留，不润色审稿人文字

## 英文摘要

- 结构：背景 → 方法 → 结果 → 结论，四要素齐全
- 结果必须含具体数值，数值与单位从原文逐字带入
- 时态：背景/结论用现在时，方法与结果用过去时
- 不引入正文没有的信息；不写 "first time" 除非原文明确声称

## 中式英语与直译腔（中译英场景）

| 问题 | 处理 |
|---|---|
| 名词化堆叠 | 适度改为动词驱动，但不改变逻辑关系 |
| 连接词滥用 | 去掉冗余的 "Moreover / Furthermore" 堆叠，保留真实逻辑连接 |
| 主语缺失 | 补出主语，但主语必须来自原文语境，不新增施事者 |
| 信息重心 | 按英语习惯把主句放前面，但保持信息等价 |
| 重复强调 | 删除同义重复，但保留强调强度（不削弱限定） |

任何文体调整都不得触发"没改坏"校验失败；冲突时以语义守恒优先。
